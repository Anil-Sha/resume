# Sk Afjal Ali - Resume

A single-page, one-column resume for software developers. Built using LaTeX templates.

### Quick start

Build using Docker:

```sh
docker build -t latex .
docker run --rm -i -v "$PWD":/data latex pdflatex sk_afjal_ali_resume.tex
```
